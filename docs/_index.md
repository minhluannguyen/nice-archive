# NICE Archive Documentation

Welcome to the NICE Archive documentation.

NICE provides reproducible environments for studying and
validating software vulnerabilities using Nix and NixOS.

## Reporting workflow

Start with [Reporting a vulnerability](reporting-vulnerabilities.md), then follow its nine steps in order. For software that is not available in nixpkgs, see [upstream and third-party builds](reporting/upstream-and-third-party-builds.md).
