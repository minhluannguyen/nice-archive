The MIT License applies to original NICE Archive components, including the framework, CLI tools, helper libraries, vulnerability recipes, and documentation.

## Using third-party exploits

NICE Archive builds upon publicly available security research. To respect the work of original authors, contributors must:

- Clearly acknowledge the original author and source.
- Document any modifications made.
- Preserve existing copyright notices and comply with the original license.

To support long-term reproducibility, we encourage referencing preserved source code through [Software Heritage](https://www.softwareheritage.org/), where appropriate. Archival does not grant additional reuse rights.
